# [Set Bits Between Given Positions](https://www.geeksforgeeks.org/problems/set-all-the-bits-in-given-range-of-a-number4538/1)
## Easy
Given a non-negative integer n and two integers l and r, set all the bits from position l to r (both inclusive) in the binary representation of n. Bit positions are numbered starting from 1 for the least significant bit. Return the resulting number.Examples:Input: n = 17, l = 2, r = 3
Output: 23
Explanation: 17 = (10001). After setting bits from position 2 to 3, the number becomes (10111) = 23.Input: n = 8, l = 1, r = 2
Output: 11
Explanation: 8 = (1000). After setting bits from position 1 to 2, the number becomes (1011) = 11.
